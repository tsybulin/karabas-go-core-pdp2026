# A PDP-11/70 core for Karabas-Go

## Подготовка SD карты
Для работы вам понадобится подготовить отдельную SD карточку в слот SD2 Karabas-go. Для записи образа диска на карту используется утилита sd-store из каталога disks/tools.
Вызовите sd-store из командной строки для получения справки.

**Внимание!** : Файловая система на карте в процессе подготовки будет изменена, данные потеряны.

Предоставляются следующие образы:
| Bank | Device | Unit | Content |
| :--: | :----: | :--: | ------- |
|   0  | RK     |  0   | Загрузочный диск с системой RT-11 v05.07 |
|   0  | RK     |  1   | Некоторые примеры и тесты на языке MACRO-11 |
|   0  | RK     |  3   | FORTRAN-11 |
|   0  | RK     |  4   | Несколько игр для PDP-11 и ДВК |
|   0  | RK     |  5   | Набор системных тестов в образах перфолент |
|   0  | RL     |  0   | Система FIG-FORTH для RT-11 / standalone |
|   0  | RL     |  2   | Исходный код RT-11 из набора source distribution set |

Для начала работы только RK0 является необходимым. Вы можете использовать любые свои образы дисков RK05, RL02, RP06. Образы simh-совместимы. Желательно использовать опцию autozap

## Загрузка ОС

После старта ядра и получения приглашения системного монитора $ введите

    DK

и нажмите Enter

## Загрузка с перфоленты

Шаги 1 .. 4 необходимы только при смене ленты.

1. Загрузите ОС
2. Просмотрите список доступных лент

```
DIR RK5:
```

3. Запишите выбранную ленту (например *BASIC.TAP*) на перфоратор

```
COPY RK5:BASIC.TAP PC:
```

4. Перезагрузите ядро по Ctrl-Alt-Backspace
5. В системном мониторе запустите абсолютный загрузчик ленты, расположенный по адресу 157500

```
L 157500
S
```

### Загрузка и запуск тестов

Вы можете использовать до 4х лент одновременно используя выбор банка PC из меню ядра (Menu+Esc).
При запуске тестов полезным будет включить в меню отображение светодиодов. Тесты после загрузки не запускаются автоматически.
Большинство тестов расчитаны на стартовый адрес 200.

1. Запишите тест в Банк 1 и перезагрузите ядро

```
COPY RP5:CKBAB0.TAP PC:
<Ctrl-Alt-Backspace>
```

2. Выберите Банк 1 и загрузите тест. После загрузки система остановится, зеленый светодиод погаснет.

```
L 157500
S
```

3. Сбросьте ядро по *F12*
4. Запустите тест

```
L 200
S
```

При работе теста 3 светодиода панели активно мигают и каждый проход теста сопровождается звуковым сингналом.
Тест бесконечен. Для выхода сбросьте ядро по *F12*

## Альтернативный монитор загрузки (bootmon)

Загружен по адресу 140000

```
L 140000
S
```

После старта нажмите Enter для получения приглашения

```
BOOT>
```

Список доступных команд можно получить введя *HELP*

## Q&A

**Q** : Я не знаю, что делать в RT-11

**A** : Ну, сыграйте в тетрис :)

Восстановите диски B0-RK0.dsk, B0-RK1.dsk, B0-RK4.dsk, загрузите систему. После загрузки введите

    @TETRIS

и нажмите Enter
